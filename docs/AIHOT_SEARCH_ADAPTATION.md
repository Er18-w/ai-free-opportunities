# AIHOT 搜索逻辑审查与本站采用方案

参考项目：[KKKKhazix/AIHOT](https://github.com/KKKKhazix/AIHOT)（MIT）。这里只采用公开的架构思想，没有复制其站名、Logo、运营数据或私有信源表。

## AIHOT 真正提高覆盖率的做法

AIHOT 的优势不是某个搜索词，而是完整流水线：RSS、网页列表、JSON、社交账号、公众号和外部脚本分别采集；信源分成官方一手、准官方、媒体与个人；新信源首次导入存量，之后只跑增量；没有可信发布时间的内容不公开；同一网址和同一内容先判重；宽松预筛后独立评分两次；最后把不同来源的同一事件归组，并优先展示官方代表稿。

它还记录抓取位置与失败状态。单次失败不会推进位置或删除旧内容；RSS 可以使用 ETag 和 Last-Modified 避免重复下载。热点按独立来源数计算，重复转载不重复加分。

## 不能原样照搬的部分

AIHOT 评价的是新闻注意力。本项目评价的是免费机会能否真实完成任务。新闻的“多人讨论”不能替代免费额度、领取门槛、截止日期和实际容量。营销限免在 AIHOT 的通用新闻评分里通常会降权，但在本站恰好是核心对象，因此必须使用独立标准。

本站也不需要先部署 PostgreSQL、队列、向量库和多次大模型调用。个人站现阶段用 JSON、GitHub Actions 和轻量规则足够；等候选数量长期超过人工复核能力，再引入模型评分。

## 本站的两种运行模式

### 首次建库：从 2026-06-01 回溯

运行 `npm run campaign:bootstrap`。本项目首次大扫除按用户确认的边界从 `2026-06-01` 回溯；旧记录只有在当前仍有效时才允许公开。

首次回溯会放宽发现分数并允许每个来源最多保留 500 条。过期线索永远不能进入公开区。AIHOT 公共接口实测只接受 `24h` 或 `7d` 窗口，不能伪装成从 6 月开始的历史数据；历史补漏由其他聚合站、RSS、厂商活动页和定向搜索承担。

### 日常运行：每天一次增量

运行 `npm run campaigns`。GitHub Actions 每天触发一次；脚本仍按每个信源的 `cadenceHours` 判断是否到期，并使用 ETag、Last-Modified 和持久化候选账本。候选记录 `firstSeenAt` 与 `lastSeenAt`；本轮未再出现只标记为 `not_seen_this_run`，不会立刻删除。连续失败会累加 `failureStreak`，旧的公开记录继续保留。

## 从文章聚类改成活动聚类

AIHOT 按“同一次发生 / 同一故事进展”归组。本站先用规范化链接，再用产品名、截止日和标题关键词归组。每个活动簇保留多个发现证据，但只产生一个待核验候选。官方来源优先成为代表证据。

相似度只是召回手段。产品不同或截止日冲突时不自动合并；最终仍由维护 Agent 判断是否同一活动、延期、复开或完全不同的福利。

## 本站的宽进严出

发现分只决定核验顺序：来源级别、权益词、价值信号、日期、官方链接加分；签到、少量日积分、排队、抽奖和邀请好友减分；代充、共享号、破解、先付费和拉人头强降分。新产品即使不在主体词表中，也可以因为明确权益和高价值信号进入候选。

公开入榜仍须同时满足：

1. 厂商官方页面或官方公开接口可验证。
2. 免费资格、地区、账号、付款要求明确。
3. 能换算成有意义的任务容量并达到本站门槛。
4. 领取、排队、限速、导出和修改成本合理。
5. 起止时间明确；没有绝对截止日时必须写明复核频率。

发现分高不代表可以公开，多个社区转述也不能替代官方证据。

## 仍需人工或 Agent 完成的搜索面

自动脚本擅长结构化订阅，不能覆盖所有封闭平台。首次回溯要从 `2026-06-01` 执行定向搜索：厂商名 × `免费模型 / 公测 / 送会员 / 兑换码 / 新用户额度 / 限时免费`，逐一查看官方活动页、公告、更新日志和官方社交账号。Linux.do、V2EX、NodeSeek、iGetoken、AI 优惠聚合器和 AIHOT 用来发现，厂商官网用来定案。

公众号、小红书、即刻和 Discord 需要登录、授权或人工选择频道，当前保留为人工巡检路径。维护者不能把“脚本抓不到”写成“没有活动”。

## 2026-10-13实际执行纠偏

重新对照上游docs/sources.md与docs/selection.md。AIHOT采用多类信源、宽预筛、独立评分、结构化、事件归组和官方优先，不是每天对所有官网穷举搜索。本站借用这一流程，但筛选目标是免费资源能否完成任务，不能把新闻热度作为免费量或能力排名。

已落地：每天先运行聚合器、社区RSS与AIHOT发现；新增iGetoken完整免费API资源目录解析；既有活动归组去重继续使用。再查新候选及权益变化所涉及的已配置官方来源。42条官方路径中7条轮换目录/近期规则每日查，其余按7天轮查；8条原始模型清单按周查；43厂商搜索表分批按7/14天轮查。AIHOT不再在两个脚本里重复请求。

无变化响应使用ETag/Last-Modified；规则变化只提取片段到候选区；重复看到不重新当作新活动，额度或期限变化会重新触发复核。首次全量模式保留，先补存量再日常增量。来源读取失败保留上次数据；没有可信日期或缺免费条件的内容仍不公开。

这是适配，未实现上游整套双模型评分系统，也未新增付费采集服务。机器预筛与现有评分先缩小范围；维护Agent只审变化片段与原文，完成资格和实用性复核后才发榜，不能宣称已实现全自动发现到发布。
