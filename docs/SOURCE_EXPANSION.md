# 模型与活动来源拓宽方案

这套路径解决两个不同问题：长期免费资源用官方目录和价格页维护；限时福利用搜索、社区和聚合线索发现，再回到官方页面验真。二者不能共用“抓到免费二字就发布”的规则。

## 1. 四层来源网

| 层级 | 作用 | 当前实现 | 能否直接公开 |
|---|---|---|---|
| 厂商官方页 | 确认额度、资格、时间和领取路径 | `data/source-map.json` 登记 43 个重点对象；官方页面按优先级轮换检查内容变化 | 仍需完成字段和任务容量审核 |
| 聚合站 | 快速发现新活动 | iGetoken、AI 优惠聚合器 | 不能 |
| 技术与福利社区 | 捕捉首发线报和体验反馈 | Linux.do、V2EX、NodeSeek、AIHOT | 不能 |
| 跨站搜索 | 补足未进入订阅流的公告、媒体稿和活动页 | Bing News RSS 自动扫；维护 Agent 执行 Google 定向查询计划 | 不能 |

微信、小红书、即刻、Discord 等登录态强、反自动化明显的渠道保留为人工巡检路径。工程不伪装成可以稳定无人值守抓取这些渠道。

## 2. 首次建库

首次建库不是把日常扫描多跑几次。执行：

```text
npm run sources:bootstrap
npm run campaign:bootstrap
```

`sources:bootstrap` 会为 43 个对象生成两段查询：

1. 最近 30 天广搜：覆盖所有重点产品和完整权益词。
2. 第 31～90 天定向补漏：只找仍可能有效的公测、长期新人包、学生活动和无明确截止时间的公告。

结果在 `.runtime/candidates/search-plan.json`。维护 Agent 必须逐条执行计划中的搜索链接，搜索结果先写候选，不能直接改公开榜。脚本同时为官方页面建立内容指纹基线，报告写入 `.runtime/reports/official-page-changes.json`。

90 天之外只在以下情况下追溯：活动仍在官网入口出现、当前账户仍能领取、或官方明确写着长期有效。纯历史新闻没有入榜价值。

## 3. 每日一次工作流

GitHub Actions 每天北京时间 09:17 运行：

1. `npm run daily`：核查长期免费层和已有目录。
2. `npm run sources:plan`：生成当天厂商轮换查询，检查官方页变化。
3. `npm run campaigns`：读取聚合、社区、AIHOT 和搜索 RSS，更新私有候选账本。
4. 测试、校验、构建；候选与报告只进入 14 天工作流 artifact。

A 级对象每天进入查询计划；B 级三天轮换；C 级七天轮换。一次抓取失败保留旧基线，不能据此宣布权益结束。

## 4. 维护 Agent 的处理顺序

每天先查看：

1. `.runtime/reports/official-page-changes.json` 中的 `changedPages`。
2. `.runtime/candidates/campaigns.json` 中高分且本轮新出现的候选。
3. `.runtime/candidates/search-plan.json` 中当天查询，优先 A 级与即将截止活动。
4. `data/campaigns.json` 中 48 小时未重新确认、无绝对截止时间的公开活动。

每条候选必须补齐：产品、权益、获取门槛、生效与截止时间、领取方法、官方来源、地区、付款方式要求、任务容量和风险说明。官方没有给出的内容写“未知”或“需登录确认”。

## 5. 去重与过滤

- 同一链接不代表同一活动；同产品、截止日和标题语义足够接近才合并。
- RSS 用标题和摘要共同匹配，避免正文写福利但标题没写“免费”时漏掉。
- “无需绑定信用卡”“不会自动续费”等否定表达不能当成风险。
- 强制绑卡并自动续费、拉人、先付款、小额签到积分、明显排队低效、已过期和仅有第三方转述的内容直接排除。
- 聚合站显示 `verified` 只代表聚合站自己的状态，本站仍要核对官方页面。

## 6. 扩充地图的方法

新增厂商时编辑 `data/source-map.json`，至少提供名称、别名、地区、类别、优先级、权益类型和一个 HTTPS 官方入口。优先级按信息价值与变化速度设置：

- A：高频发布免费模型、公测或会员活动。
- B：有稳定免费层，偶尔调整额度或活动。
- C：低频变化、需要周度覆盖或当前免费条件存疑。

登记新对象不等于新增榜单记录。通过官方证据、任务容量和使用成本审核后，才更新 `data/campaigns.json`、`data/catalog.json` 或 `data/radar.json`。
